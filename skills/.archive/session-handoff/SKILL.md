# Session Handoff — 跨会话衔接

## 触发条件

用户说出以下关键词时，**必须立即**调用 `session_search()` 定位上一次相关会话。
- "继续" + 项目/工具名（如"继续 MCP"、"继续 STS2 Mod"）
- "接上"、"上次那个"、"之前那个"、"之前的事"
- "还记得我们做的..." / "之前搞的那个..."
- "接着之前的工作"
- 简单提及之前讨论过的游戏名/工具名时，也优先搜一下再判断

## 行为规则

1. **不要问"什么事"** — 直接搜。如果搜不到再问。
2. 搜索策略：
   - 用项目名 + 关键动词组合（如 "Frida MCP 连接"、"STS2 Mod"、"Ghidra 反编译"）
   - 搜不到时换同义词再搜一次
   - 两次搜不到再和用户确认
3. 找到后快速总结找到的内容，提出"上次到哪一步 + 下一步选项"，让用户选择继续方向

## 记忆使用策略

- 跨越多次会话的复杂任务（Mod 开发、逆向分析等），在每次对话结束时用 memory 工具保存一个**简短的状态行**
- 保存前检查记忆容量，如果满则压缩/替换较旧的条目
- 状态行格式：`[项目名] 进度摘要 | 下一步`

## 跟 PLAN 模式的关系

- 如果是新任务 → 走 PLAN 模式先写计划
- 如果是续接旧任务 → 先 session_search 找到进度，根据进度决定是否需要新计划
