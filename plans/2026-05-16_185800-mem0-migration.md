# Mem0 记忆插件迁移方案

## 目标

将 Hermes 默认记忆（2,200 字符硬上限）替换为 Mem0 云端记忆（无大小限制，自动去重，语义检索）。

## 前提

你需要提供 Mem0 API Key（你说了你来搞定）。

## 步骤

### 1. 获取 API Key

去 https://www.mem0.ai 注册账号 → Dashboard → 复制 API Key。

### 2. 将 Key 写入 Hermes 环境变量

编辑 `~/.hermes/.env`（或创建它），添加一行：

```
MEM0_API_KEY=m0-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

⚠ 不要放进 `config.yaml`，不要在对话里粘贴。.env 文件是本地存储，只有 Hermes 读到。

### 3. 修改配置文件

`~/.hermes/config.yaml` 第 295 行，把：

```yaml
memory:
  provider: ''
```

改成：

```yaml
memory:
  provider: mem0
```

### 4. 重启 Hermes

新会话生效。之后我的 `memory()` 工具会自动走 Mem0 的 API，不再受 2,200 字符限制。

### 5. 验证

在新会话里让我存一条新记忆，然后跨会话验证是否能召回。

## 注意事项

- ⚠ 切换后现有记忆（当前 7 条，381 字符）不会自动迁移到 Mem0，那 7 条会丢失。需要我在切换前先导出到 skill 里作为备份
- Mem0 是云端服务，离线时记忆不可用（会触发断路器暂停重试）
- 不需要手动压缩了——Mem0 自带 LLM 事实提取 + 自动去重 + 语义搜索

## 风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| 现有记忆丢失 | 丢失 7 条偏好/配置信息 | 切换前导出到 skill |
| API Key 泄露 | 他人可读写你的记忆 | Key 放 .env，不进出对话 |
| 网络不可用 | 记忆功能停摆 | 断路器 5 次失败后暂停 120 秒，不影响对话 |
